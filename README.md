# SpringBoot图书管理系统简介

## 核心功能
- 登录注册
- 数据总览
- 书籍信息增删改查
- 图书借阅
- 图书归还
- 个人信息修改
- 读者管理
- 借阅状态管理
- 批量删除
- 分页查询

## 适用场景
- 学校图书馆
- 公共图书馆
- 企业图书室
- 个人图书管理

## 技术特点
- 采用Java语言编写
- SpringBoot框架构建
- MySQL数据库存储
- Vue前端技术实现界面交互
